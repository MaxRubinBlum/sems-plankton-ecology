# Supplementary environmental PCA

Reproducibility notes for the supplementary environmental ordination.

## Panel a: CTD PCA

PCA of standardized CTD variables associated with the microbial samples:

- temperature
- salinity
- dissolved oxygen
- fluorescence

Complete cases: n = 249. PC1 explains 57.1% and PC2 25.5% of variance.

## Panel b: CTD + chemistry PCA

PCA of standardized CTD variables plus the chemistry variables with sufficient coverage across the full water column:

- temperature
- salinity
- dissolved oxygen
- fluorescence
- nitrate + nitrite
- phosphate
- silicate
- pH

Complete cases: n = 67. PC1 explains 65.9% and PC2 17.0% of variance.

The restricted chemistry set was chosen to retain deep-water observations. Chlorophyll chemistry, Winkler oxygen and alkalinity were not included because requiring complete observations for these variables removed most deep samples. The retained panel-b dataset contains 10 surface, 16 near-surface, 8 DCM, 12 below-DCM, 12 samples at 300–600 m, 8 below 600 m, and 1 near-bottom sample.

PCA variables are z-standardized before ordination. Points are colored by vertical habitat and symbols indicate winter or summer. Arrows show variable loadings.

The source table used for this analysis is the integrated 18S sample environmental table generated by the environmental integration workflow. The figure should be regenerated from that table rather than from plotted coordinates.

# Syndiniales partner-repertoire stability — Phase 3

Phase 3 asks whether the **identity of Syndiniales-associated protist partners** changes across the 220-m ecological boundary, after Phase 2 showed strong changes in association strength.

## Why this analysis is needed

The independently inferred upper and deep FlashWeave networks had only one exact parasite–protist edge in common. Phase-2 cross-regime retesting showed that this dramatically overstated biological turnover: 95 associations had residual support on both sides of 220 m.

Phase 3 therefore does **not** use exact FlashWeave edge overlap as the turnover statistic. It starts from the Phase-2 `cross_regime_edge_retesting.csv` table and compares the supported partner sets of each parasite lineage between regimes.

## Support inherited from Phase 2

A parasite–partner association is considered supported within a regime when Phase 2 found:

- both features present in the regime-specific analysis,
- environmentally residualized association with BH-FDR `q < 0.05`, and
- `|rho| >= 0.20`.

The Phase-2 residualization accounts for hydrographic/spatial metadata. Phase 3 does not refit those models; it operates on the validated Phase-2 edge table.

## Strict partner-turnover null

The final null is deliberately conservative. For **each parasite lineage separately**, random partner sets preserve:

1. the observed number of supported partners in each regime;
2. the observed broad partner-guild composition in each regime;
3. whether each candidate partner is available/testable above and below 220 m; and
4. the parasite-specific candidate-partner universe, defined as the union of candidate edges that entered Phase-2 cross-regime retesting for that parasite.

Exact overlap is simulated analytically by guild using hypergeometric sampling. The archived run uses **20,000 permutations** and deterministic seed **20260826**. Benjamini–Hochberg correction is applied across lineage-level tests.

This null is preferable to drawing from the entire protist community because it asks whether partner identity changes **within the interaction space already supported for that parasite**, rather than comparing against biologically unrealistic random partners.

## Archived result

Phase 2 contributed:

- 241 residual-supported associations at `<=220 m`;
- 140 residual-supported associations at `>220 m`;
- 95 associations supported in both regimes;
- 45 parasite lineages with at least one supported partner in both regimes.

Of the 95 shared associations, **93 retained the same sign** and only **2 reversed sign**.

Under the strict parasite-specific candidate-universe null:

- observed exact shared partner edges: **95**;
- null expectation: **97.13**;
- 95% null interval: **92–102**;
- lower-tail P (excess turnover): **0.274**;
- upper-tail P (excess conservation): **0.836**;
- parasite lineages with significant excess turnover after FDR: **0/45**;
- parasite lineages with significant excess conservation after FDR: **0/45**.

The supported interpretation is therefore:

> The 220-m transition changes the **strength of many Syndiniales–protist associations** more clearly than it changes the underlying partner repertoire.

This result qualifies Phase 2: lineage-specific coupling changes are real, but the data do not support wholesale partner replacement across the ecological boundary.

## Interpretation guardrails

- Association turnover is not synonymous with host switching.
- Failure of a sparse network method to re-select an edge is not evidence of biological disappearance.
- The strict null supports neither excess global turnover nor excess global conservation.
- Phase 2 provides evidence for **changes in association strength**; Phase 3 shows that these changes generally occur within a constrained candidate-partner repertoire.
- Candidate hosts remain hypotheses unless supported independently by microscopy, culture, FISH, single-cell data, or sequence-level host references.

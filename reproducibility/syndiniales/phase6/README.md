# Sequence-level validation targets — Phase 6

Phase 6 prepares the ASV targets needed for BLAST/phylogenetic validation of high-priority candidate host associations.

The repository and user Library were searched for the matching unfiltered 18S representative-sequence FASTA/QIIME artifact, but no sequence file containing these OTUIDs was available. Therefore no BLAST or phylogeny was fabricated.

Archived outputs identify the priority aggregate pairs, their constituent OTUIDs, dominant ASVs, and the 78 representative-sequence IDs requested for follow-up.

## Required continuation

Provide the 18S representative-sequence FASTA (or QIIME2 `rep-seqs.qza`) whose record identifiers match the OTUIDs. Then extract the requested OTUIDs, BLAST them against curated/NCBI references, and place high-priority Syndiniales sequences against characterized Group I/II/*Amoebophrya*/*Euduboscquella* references.

Until that file is available, taxonomic/network evidence remains the highest sequence resolution justified by the dataset.

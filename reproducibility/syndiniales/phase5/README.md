# Targeted 99%-OTU-level validation — Phase 5

Phase 5 tests whether high-priority taxon-aggregate parasite–protist associations are supported by specific original **99% OTU features** rather than being created only by taxonomic aggregation.

## Important provenance correction

The uploaded `rep-seqs-99.qza` resolves the feature provenance unambiguously. QIIME 2 provenance shows that sequences were first generated by `q2-dada2 denoise_paired` with hashed feature IDs and were then clustered by `q2-vsearch cluster_features_de_novo` with `perc_identity = 0.99`.

Therefore the feature IDs used in the current OTU table are **99% de-novo clusters represented by centroid sequences**. They are not unclustered ASVs. The numerical Phase-5 analysis is unchanged; only the biological/statistical unit and terminology are corrected here.

## Procedure

1. Map each candidate aggregate feature back to its constituent 99% OTU features using the same aggregation logic used for FlashWeave input.
2. Within the 249 complete environmental cases, retain constituent OTUs with prevalence >=2% and >=50 total reads.
3. For broad aggregates, retain OTUs accounting for approximately 90% of reads, capped at 20 OTUs per aggregate.
4. Residualize log1p OTU abundances against the exact metadata matrix supplied to FlashWeave.
5. Test parasite-OTU × partner-OTU residual Spearman correlations where co-presence >=20 samples.
6. Apply one BH-FDR correction across all targeted OTU-pair tests; support requires q<0.05 and rho>=0.20.

## Archived result

102 constituent 99%-OTU pairs were testable. 46 retained positive support after global FDR. Seven of nine aggregate candidates with sufficient constituent-OTU co-presence contained at least one supported specific OTU pair.

This remains a targeted sensitivity analysis, not an exhaustive search of all possible OTU pairs. Because 99% clustering can merge closely related sequence variants, these results support sequence-cluster-level recurrence but must not be described as ASV-level validation.

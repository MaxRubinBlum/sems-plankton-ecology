# Figure 2 results

Compact checked outputs for the revised matched transition analysis are versioned here. The primary scan uses 252 samples shared by 16S, 18S and the trophic table at ≤650 m, representing 52 independent sampling profiles. Candidate-depth curves use a minimum of 12 spanning profiles; the joint bootstrap retains the conservative 15-profile criterion. `minimum_profile_sensitivity.csv` shows that minimum support values of 10, 12 and 15 recover the same transition optima.

The final figure overlays the full 2018–2026 16S scan as a dashed contextual curve and uses `dcm_peaks_from_ctd.csv` only for CTD-derived DCM background shading. Full scan curves, bootstrap replicate tables, metadata audit and SVG/PDF/PNG figure files are regenerated by the scripts in `reproducibility/fig02/`.
